# ThermoGIS

ThermoGIS is a geospatial AI prototype for detecting, classifying, and monitoring thermal sources.

It combines NASA FIRMS, Sentinel-1/2, ESA WorldCover, and OpenStreetMap data to add context to thermal hotspots.

The system aims to classify thermal events as:

* Industrial Fire
* Gas Flare
* Mining Activity
* Agricultural Burning
* Wildfire

## Tech Stack

Python, FastAPI, PostgreSQL, PostGIS, LightGBM, ST-DBSCAN, SHAP, React, MapLibre, Docker.
